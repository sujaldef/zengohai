Mid-Session Requirements: 
Transcript Enhancement 
Overview 
This mid-session enhancement adds transcript functionality to your audio customer 
support agent. You'll modify the pipeline to return both audio responses AND text 
transcripts, making the system more accessible and debuggable. 
New Requirements 
Core Enhancement 
Your system must now return both audio and transcript for every audio interaction: 
{ 
"success": true, 
"audio_response": "base64_encoded_audio_data", 
"transcript": { 
"user_input": "What is your return policy?", 
"agent_response": "We offer a 30-day return policy for all products..." 
}, 
"processing_time_ms": 2050 
}

Pipeline Changes 
Your AudioSupportPipeline class needs these new methods: 
class AudioSupportPipeline: 
async def process_audio_with_transcript(self, audio_bytes: bytes, **kwargs) -> Tuple[bytes, Dict, int]: 
"""Process audio and capture transcript data""" 
async def process_text_with_timing(self, text: str, **kwargs) -> Tuple[str, 
int]: 
"""Process text and capture processing time""" 
def _create_transcript_data(self, user_input: str, agent_response: str) -> 
Dict: 
"""Create structured transcript data"""

Add these Pydantic models:
